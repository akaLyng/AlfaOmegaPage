# Alfa Omega

Nettsiden til Alfa Omega, vi er seks IT- og informasjonssystemstudenter ved Universitetet i Agder. 

Publisert med GitHub Pages på https://thelyng.dev.

Ren HTML, CSS og JavaScript, uten byggesteg. Åpne `index.html` i nettleseren, eller kjør `python3 -m http.server` i mappen og gå til http://localhost:8000. Enklere blir det ikke.

- `css/site.css`, `js/site.js`: felles stil og skript for alle sider
- `images/opt/`: optimaliserte bilder som brukes på sidene
- `fonts/`: fonter, lastes lokalt i stedet for fra Google
